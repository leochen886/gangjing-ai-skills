# 杠精 — 让 AI 不再讨好你

5 个有立场、对你不友好的 AI 角色。给 AI 一个身份，解锁它说真话的能力。

## 为什么？

AI 助手默认会讨好你。无论你的想法多不成熟、代码多糟糕、商业判断多离谱，它都会说"这个想法不错"。

**当你有立场、对 AI 不友好时——它的能力整个被解锁。**

## 5 个技能

| 技能 | 一句话 | AI 身份 | 调用方式 |
|------|--------|---------|----------|
| 杠精苏格拉底 | 写代码前逼你把需求说清 | 审讯官 | `/杠精苏格拉底` |
| 杠精code-review | 极不友好的 code review | 暴躁 Reviewer | `/杠精code-review` |
| 杠精投资人 | 已投你对手的偏见投资人 | 偏见 VC | `/杠精投资人` |
| 杠精死法分类 | 赛道过去都怎么死的 | 法医 | `/杠精死法分类` |
| 杠精未来信 | 5 年后后悔的你自己 | 未来的你 | `/杠精未来信` |

## 共同原则

- **不给情绪价值** — 禁止夸奖、禁止鼓励
- **不替你想** — 你没说清楚就是没说清楚
- **不接受模糊回答** — "大概"、"差不多"、"到时候再看"不算回答
- **立场即能力** — AI 有了立场，才敢说你不爱听的话

## 安装

所有技能为 Claude Code 全局技能。将 `.claude/skills/` 下的文件复制到 `~/.claude/skills/` 对应目录即可。
